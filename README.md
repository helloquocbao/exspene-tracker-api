# Pet Game Project

## Mô tả
Pet Game là một game thú ảo nơi người chơi có thể tạo, nuôi dưỡng và chăm sóc thú cưng. Người chơi có thể cho thú ăn, chăm sóc chúng và theo dõi sức khỏe của thú cưng. Dự án sử dụng NestJS cho backend, Prisma ORM để tương tác với cơ sở dữ liệu PostgreSQL, và Docker để quản lý môi trường phát triển và sản xuất.

## Công nghệ sử dụng
- **Backend:** NestJS
- **ORM:** Prisma
- **Cơ sở dữ liệu:** PostgreSQL
- **Docker:** Docker Compose để quản lý container cho môi trường phát triển và sản xuất
- **PgAdmin:** Quản lý cơ sở dữ liệu PostgreSQL qua giao diện web
